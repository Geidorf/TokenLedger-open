# 本机网关能力与资源边界 v1（T10.300a/b）

仅监听127.0.0.1，凭据仍由Rust读取；API调用与Agent配置接入各有独立证据。统计遵循Stats v2§2.5，不用请求成功状态推断费用可得。

## 尝试身份与协议

`requestId`为每次上游尝试唯一ID，可选`logicalRequestId`连接同一逻辑调用的失败转移。尝试日志保留所有失败；计费先排除零Token诊断，成功按逻辑ID唯一，失败有用量按尝试保留。旧行兼容见Stats v2§2.5。

原生Responses/Anthropic成员保留原协议内容。转Chat前逐字段/内容块验证：实现覆盖文本、可表示图片、函数工具及受支持custom工具包装；document、server tools、未知内容/字段、无法表达的签名thinking/缓存控制等要求原生成员。结构错误在连接前拒绝；路由组可跳过无法表达的成员，全部不支持则400。不得先删除语义再发送；unsupported真实HTTP测试要求上游请求数为0。

Gemini模型发现/Agent配置使用完整`供应商/模型`；每个请求都必须携带完整身份（路径斜线可URL编码）。裸模型及缺失身份返回明确错误，不采用进程全局最近模型，不借用其他客户端状态。

T10.306b：Gemini 在转换前检查原始对象，无法表达的 googleSearch、PDF/音视频、thinkingConfig、未知字段和多函数允许列表直接拒绝，上游零请求；支持的 HTTP 图片地址先规范化 URL，混合大小写 scheme 不丢图片语义。

## 运行与上游认证（T10.306b）

关闭总开关或停止网关会撤销本次启动的请求许可、同步释放监听端口并回收已接收连接；旧保活连接与仍在等待凭据的请求不得继续产生新上游调用。重新启动创建独立许可，固定端口立即重启不依赖旧异步任务何时被调度回收。

供应商可选 `authMode: key | none`，旧配置缺失按 key。none 仅限解析后的 literal 127.0.0.1/::1，保存与发送均校验，不跟随重定向；只省略上游认证头，本机网关 token 认证始终保留。Ollama/LM Studio 新预设显式选择 none；已有记录保守兼容，由用户编辑选择，不据名称自动降级认证。

## 固定资源上限

| 资源 | 生产上限 |
|---|---|
| 请求体 / 读取 | 32MiB / 30秒 |
| 上游连接 / DNS发送至响应头 | 15秒 / 60秒 |
| 非流式attempt总时限 / 响应 | 300秒 / 32MiB |
| 上游错误体 | 64KiB / 30秒 |
| SSE空闲时限 / 原始流累计 | 120秒 / 64MiB（不使用短总时限截断持续推理） |
| SSE单行 / 单事件 | 1MiB / 2MiB |
| 转换累计输入 / 单输出事件 / 输出总量 | 8MiB / 8MiB / 64MiB |
| 客户端背压 / 发送队列 | 30秒 / 2项 |
| HTTP连接 / 头缓冲 / 头时限 | 32 / 64KiB / 30秒 |
| 活跃请求 | 8，响应体含SSE消费或取消前占槽，无等待队列 |
| 凭据读取 | 4槽 / 15秒；超时未结束的工作仍占槽 |

这些是实现的安全预算，不是延迟承诺。测试通过短时限沿相同HTTP路径注入停顿、超量、慢上传、缺换行、背压及取消；不对真实付费API取证。新供应商或协议能力必须补同类测试，不能通过放宽未知字段实现静默降级。

## 配置事务与脱敏

多文件apply/restore/force包含配置、备份与manifest的前像/后像。prepared journal和哈希绑定commit marker持久化；commit前故障回滚，commit后重放。恢复路径白名单由当前Agent spec产生，不能信任journal内任意路径；所有目标先核对当前字节为已知前像/后像，外部漂移则保留记录和备份、不覆盖。

inspect/preview/apply/restore及应用启动恢复未完事务；无pending时启动不读取用户配置。旧manifest保守兼容，孤立/损坏备份拒绝覆盖。预览只显示结构changed-leaf projection及递归脱敏值，无原文上下文/注释；解析错误只给静态文案。临时文件与journal保护凭据，不能把备份目录当作可分享证据。

T10.306a：再次应用不改写首次有效备份；Codex 仅按已应用的托管字段恢复，同时保留用户其他设置。无法证明归属、原备份缺失或合并后超过大小上限均拒绝；强制恢复解析失败配置仍只使用已验证的原备份。通用多文件配置检测到应用后的外部漂移时停止，保留恢复材料。
