## 四、需要维护者亲手做的事

1. **执行 `supabase db push`**。下面这些功能的云端部分要部署后才能用：实时路由快照（#31）、热力图逐日与活动节律（#67）、权限加固（#74）、预算快照（#78），以后还有云端用量维度。部署后可以在 Supabase Advisor 复核 sync_state 和 pgcrypto 的告警是否消失。
2. **仓库 Settings › Pages › Source 选「GitHub Actions」**。不设的话 #106 合并后 main 上的 deploy job 会红，但不会触发 main 红灯告警。
3. **决定云同步上传的设备标识**：继续用主机名，还是改用随机设备 ID。建议改用随机 ID，因为主机名可能带个人信息。手册隐私章目前写的是主机名。
4. **Android 依赖漏洞扫描**：按 `docs/android-dependency-scan.md` 在本机跑一次（云端访问不到漏洞库）。
5. **真机验收**：
   - 桌面安装包：Windows NSIS/MSI、macOS DMG、Linux deb/AppImage/rpm。Linux 要在 GNOME 和 KDE 上看托盘菜单、登录自启、重启后是否仍保持登录（#110 合并后）。
   - 托盘：Windows 徽章在 16/24px 下是否看得清，macOS 菜单栏标题。
   - Android：快捷设置磁贴、实时路由小组件、额度条小组件、锁屏壁纸、预算提醒通知（需先 db push 并在桌面打开「同步到手机」）、TalkBack 走查。
   - 周报：系统通知与打印 PDF 对话框。
   - 备份：一台电脑导出，另一台恢复；钥匙串；退出重开后的重建。
   - Webhook：用真实机器人地址收一次消息。
   - MCP 服务：用 Agent 客户端实际连一次。
6. **Cindy 真机探针**：在 Windows 上跑 `cargo test -- --ignored cindy_real_machine_probe --nocapture`，只打印汇总数。
7. **联网核实价格**（云端访问不到官方页面）：缓存读价（gemini-2.5-flash、minimax-m2.x、ernie-5.x），缓存写价（minimax-m3、Kimi K2），旧价（GPT-5.6 Sol 在 2026-08-21 的旧价、DeepSeek 峰谷价、MiMo V2.5）。
