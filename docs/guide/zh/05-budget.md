# 5. 预算提醒

[← 网关与路由组](04-gateway-routing.md) · [目录](README.md) · 下一章：[云端同步与手机端 →](06-cloud-mobile.md)

在 **设置 › 预算提醒** 里，可以给某个周期、某个范围设一条费用或 Token 上限，用量接近或超出时提醒你。

![设置 › 预算提醒](../images/settings-budget.png)

## 新增一条预算

| 选项 | 可选值 |
| --- | --- |
| 周期 | 今日、本周（从周一算起）、本月；与看板上的同名范围是同一个日历边界 |
| 范围 | 全部用量，或某个 Agent、某个模型、某个账号 |
| 口径 | 预估费用（美元，与看板费用一致），或有效 Token（输入 + 输出，不含缓存） |
| 上限 | 大于 0 的数 |
| 接近比例 | 用到 50%、70%、80%（默认）或 90% 时先提醒一次 |

选 Agent 或模型时，输入框会列出本月出现过的名字供你挑。**账号**指模型网关记下的转发目标（供应商），所以只有经过网关的请求能按账号统计；本机没有网关记录时，账号预算显示为不可得。

最多可以建 32 条。每条都能停用、编辑或删除；改了周期、范围、口径或上限，就当作一条新预算重新计数。

## 怎么提醒

- **系统通知**：打开顶部的「接近或超出预算时提醒」后，每条预算在每个周期里「接近」和「超出」各通知一次；直接超出时只发一条超出。全局每小时最多 4 条，被限流的下次检查再发。这个开关默认关闭。
- **托盘提示**：不管通知开没开，托盘图标的悬停提示都会追加一行，例如「预算：1 项超出 · 2 项接近上限」。
- **设置页**：每条预算下方有进度条，写明已用多少、上限多少、百分比。

通知只写范围名、周期与百分比，例如「本月费用预算已用 85%」，不写金额和账号细节，在会议投屏时弹出也不泄露数字。

## 几个边界

- **只看已经发生的用量**，不按速度预测「月底会超」。
- 有未核价模型导致费用不完整、或者账号维度没有网关数据时，这条预算显示为**不可得**，不会当成 0，也不会提醒。
- TokenLedger 会在后台扫描写入新记录、手动刷新、跨日时检查预算；有预算时另外每 5 分钟检查一次，这样只经网关的用量也能及时提醒。
- 预算规则只保存在这台电脑，不进入云端同步。
- 订阅额度窗口快用完的提醒是另一项功能，在「设置 › 订阅额度 › 额度提醒」，见[第 3 章](03-usage.md#额度)。
