# 8. 托盘与菜单栏

[← 壁纸与小组件](07-wallpaper-widgets.md) · [目录](README.md) · 下一章：[隐私说明 →](09-privacy.md)

TokenLedger 常驻在 Windows 的系统托盘（任务栏右下角）或 macOS 的菜单栏里。关闭主窗口只是把它藏回托盘，后台扫描、网关和同步照常运行；要彻底退出，用托盘菜单里的「退出」。

## 托盘图标

| 操作 | 效果 |
| --- | --- |
| 鼠标指向图标 | 停留一小会儿后弹出托盘挂件，移开自动收起 |
| 单击 | 打开或收起托盘挂件；挂件弹出后单击可以钉住，不再自动收起 |
| 双击 | 打开主窗口 |
| 右键（macOS 上按住 Control 点按） | 托盘菜单 |

托盘菜单有：显示窗口、显示 / 隐藏托盘挂件、桌面小组件（长驻桌面）、退出。

悬停提示跟随本机今天的用量和最紧额度；设了[预算](05-budget.md)时还会追加「预算：1 项超出 · 2 项接近上限」这样一行。

## 菜单栏数字与托盘徽章

在 **设置 › 扫描与启动 › 菜单栏与托盘** 打开「在菜单栏 / 托盘上显示数字」，再选择「显示哪个数字」：

- **今日预估费用**：显示今天的费用摘要。
- **最紧额度**：显示所有可读额度窗口中最低的可用百分比。

macOS 把数字写在菜单栏图标旁；Windows 把托盘图标换成数字徽章。图标空间有限，数字会缩写，详细数值可在悬停提示或挂件里查看。读不到的数据用占位符表示，不按零处理。关掉数字显示后恢复普通图标，悬停提示仍可查看。

## 托盘挂件

<img src="../images/tray-widget.png" alt="托盘挂件" width="300">

从托盘图标旁弹出的小窗，不占任务栏、不抢焦点。顶部可以临时切换今日、本周、本月，右上角是刷新、打开主窗口、设置、收起。

在 **设置 › 桌面挂件 › 托盘挂件** 里可以调：

- **指向托盘图标时弹出**：关掉后只有单击才弹出。
- **停留多久才弹出**：立即、0.25 秒、0.45 秒（标准）、0.9 秒，防止鼠标路过时误触。
- **启动时直接钉住托盘挂件**：开机后直接显示。
- **板式、主题、默认范围、额度来源**：与[桌面小组件](07-wallpaper-widgets.md#桌面小组件电脑)的选项相同，两者各配各的。

## 面板与快捷开关

把托盘挂件的板式选为「面板」，可以在同一张卡片里查看今日预估费用、有效 Token、记录数、额度可用比例及重置倒计时，以及网关状态和最近路由。面板里的实时路由随网关状态更新；没有可用额度或路由数据时会说明原因。

面板底部有三个快捷开关：

| 开关 | 作用 |
| --- | --- |
| 网关 | 可以开启已配置的网关；关闭时会带你回主窗口检查仍在使用网关的 Agent |
| 后台同步 | 控制扫描后的自动云同步；暂停后仍可手动同步 |
| 后台扫描 | 控制定时扫描；暂停后主窗口顶栏的手动刷新仍可使用 |

开启网关前需要至少一个可用供应商；云账号未登录等条件不满足时，面板会显示限制原因。暂停后台工作不会清空已有账本，也不等于退出应用。

## 开机与启动

在 **设置 › 扫描与启动**：

- **开机自动启动**：默认关闭。Windows、macOS 和 Linux 可登记当前用户的登录启动项；开关反映系统读取结果，读取失败时使用“重试”。系统禁止启动或要求后台授权时，按提示在系统设置中处理后重新读取。
- **启动时最小化到托盘**：启动时不显示主窗口，只在托盘里待命。
- **扫描间隔**：默认约 15 分钟，最短 1 分钟。

需要临时强制显示主窗口时，可以带 `--show` 参数启动（macOS：`open -n /Applications/tokenledger.app --args --show`）。

自启与最小化是两个独立选择。在系统中禁用或删除启动项后，重新打开应用不会自动恢复它；修改其他设置或恢复备份也不会开启自启。操作失败会显示原因并尝试恢复原登记；如果同时提示恢复失败，请在系统启动项设置中核对。

Windows 上移动程序后，旧启动项的位置可能失效。应用会提示位置不一致；需要继续自启时，点击「按当前位置重新启用」。只有这次明确操作才会更新启动项，成功回读后开关才显示已开启。
