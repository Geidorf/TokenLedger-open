# 9. 隐私说明

[← 托盘与菜单栏](08-tray.md) · [目录](README.md) · 下一章：[常见问题 →](10-faq.md)

一句话：**所有统计都先在本机完成；默认什么都不上传。** 只有你主动打开云端同步，汇总后的数字才会上传，而且是上传到你自己的 Supabase 项目。

## 只留在本机的

| 数据 | 存在哪里 |
| --- | --- |
| 各 AI 工具的原始日志与数据库 | 原地读取，不复制、不修改 |
| 逐条用量账本（含会话 ID、时间、模型、Token） | 本机数据库 `tokenboard.db` |
| 提示词、模型回复、文件内容 | TokenLedger 不读取也不保存这些内容，只取日志里的用量字段 |
| 供应商 API key、公司额度接口 key、云端登录会话 | 系统钥匙串（Windows 凭据管理器 / macOS 钥匙串） |
| 模型网关的请求账本与供应商健康度 | 本机应用数据目录 |
| 预算规则与提醒记录 | 本机应用数据目录 |
| 项目文件夹名（「按项目统计」开启时） | 本机数据库，不参与同步 |
| 从外部网关 WebDAV 读到的其他电脑共享用量 | 只并入本机统计，永不上传 |
| 自定义价格、界面设置 | 本机应用数据目录 |

扫描只读取各 AI 工具自己的日志与数据库目录，不碰浏览器数据、Cookie、SSH 密钥或其他通用敏感位置。额度来源不复制 OAuth Token，不调用任何消费级产品的未公开内部接口。

## 打开云端同步后会上传的

上传目的地是你在「设置 › 云端账户」里填的 Supabase 项目。每个账号只能读写自己的数据（数据库行级安全策略隔离）。

| 什么时候 | 上传什么 | 不含什么 |
| --- | --- | --- |
| 云端同步（登录后） | 按「设备 × 工具 × 模型 × 小时」聚合的行：设备名（电脑的主机名）、工具名、模型名、小时、输入 / 输出 / 缓存 Token、请求数、预估费用、其中经网关的请求数 | 会话 ID、提示词、回复、文件路径、项目名、供应商 key |
| 账户 | 注册用的邮箱，由 Supabase Auth 保存 | — |
| 额度的跨设备同步（单独开关，默认关） | 各额度窗口的可用比例、重置时间、观测时间与来源名称；已开启的供应商余额只传金额与币种 | 订阅账号凭据、Cookie、账号邮箱与组织名 |
| 预算同步到手机（单独开关，默认关） | 每条预算的范围名（与系统通知相同：Agent、模型或账号的显示名，或「全部用量」）、周期、已用百分比（取整）与级别；设备用一串不可逆的编号，不含主机名 | 金额、上限、读不到数的预算；关闭开关时删除，3 天未更新的由云端清理 |
| 手机动态壁纸（单独开关，默认关） | 最近几分钟的路由快照：Agent 名、`供应商/模型`、状态码、时间 | 会话、账号、密钥、错误正文、请求内容；关闭开关时删除，云端每天清理过期快照 |

如果不想让电脑的主机名出现在云端，可以在开启同步前把电脑名改成一个不含个人信息的名字。

## TokenLedger 会主动连接的地址

| 连接 | 什么时候 |
| --- | --- |
| 你的 Supabase 项目 | 只在开启云端同步后 |
| 你配置的供应商接口 | 模型网关转发请求、读取供应商余额时 |
| 你授权的额度来源 | 只在对应来源的开关打开后 |
| `models.dev` 公开模型目录 | 在「模型价格」里搜索待核价模型的报价时，缓存 24 小时 |
| 一言公开句子接口（仅 Android） | 待机屏的「今日一句」每天最多请求一次，失败时用内置语句 |

TokenLedger 不包含任何统计分析或遥测 SDK。

## 截图与分享

- 「数据战报」导出前可以预览，并可隐藏费用。
- 「按项目统计」可以打开「隐藏项目名」，截图时显示为「项目 1」这类代称。
- Android 的「隐藏费用」把金额换成星号，同时作用于小组件。

## 删除数据

- **本机**：「设置 › 数据与帮助 › 危险区 › 清理旧数据」删除某个日期之前的记录；卸载后删除[数据目录](01-install.md#升级与卸载)可彻底清除。
- **云端**：数据在你自己的 Supabase 项目里，可以在 Supabase 控制台直接删除，或删除整个项目。额度来源可以在「设置 › 订阅额度」里单独「删除云端快照」。
