# 10. 常见问题

[← 隐私说明](09-privacy.md) · [目录](README.md) · 下一章：[请求日志 →](11-request-log.md)

## 安装与启动

**Windows 提示「Windows 已保护你的电脑」，没有运行按钮。**
先点「更多信息」，按钮才会出现。详见[安装](01-install.md#windows)。

**macOS 提示「无法打开，因为无法验证开发者」。**
到「系统设置 › 隐私与安全性」点「仍要打开」。详见[安装](01-install.md#macos)。

**启动后看不到窗口。**
多半是开了「启动时最小化到托盘」。双击托盘（菜单栏）图标打开主窗口，或带 `--show` 参数启动。

## 数据与统计

**某个工具的用量没有出现。**
先确认这个工具在这台电脑上产生过会话，然后点「刷新扫描」。Codex 装在非默认位置时，在「设置 › 扫描与启动 › 额外的 Codex 日志目录」填上它的目录。支持的工具清单见仓库 [README](../../../README.md#核心功能)。

**为什么有效 Token 比工具自己显示的少？**
TokenLedger 的有效 Token 只算输入 + 输出，缓存读写单独列出。切到「概览含缓存」就能看到含缓存的总量。

**预估费用和账单对不上。**
预估费用按本机价格表估算，带 `≈` 号，用于看趋势和相对多少，不能当账单。新模型会先进「设置 › 模型价格」的待核价列表，按工具兜底费率暂估，你可以搜索公开报价一键导入，或手动填写单价。

**同一个请求会不会被算两次？**
不会。经过模型网关的请求，网关账本和 Agent 日志里各有一份，TokenLedger 在本机合并后只算一次。从外部网关 WebDAV 读到的其他电脑共享用量，只勾选没装 TokenLedger 的电脑，否则会重复。

**看板上写「不可得」。**
表示这个数字读不到（例如有未核价模型导致费用不完整，或者没有网关记录所以没有账号维度），TokenLedger 不会用 0 冒充。

## 云端与手机

**「检查账户状态」时系统要我输入密码。**
这是系统钥匙串的授权，输入的是电脑的开机密码，不是云端账户密码。

**登录报找不到某个函数（`Could not find the function …`）。**
云端还没部署最新迁移。在仓库目录执行 `supabase db push`，等一两分钟让 Supabase 刷新后再试。见[云端同步](06-cloud-mobile.md#准备云端只做一次)。

**手机上的数字和电脑不一样。**
手机看的是云端汇总：只包含已经同步上去的数据，并且要等云端汇总刷新。切到电脑的「云端汇总」对照；电脑的「本地机器」只算这一台。另外手机默认用人民币显示费用，电脑用美元。

**手机锁屏壁纸显示「云端尚未部署」或「桌面离线」。**
前者执行 `supabase db push`；后者检查电脑是否开着 TokenLedger、是否打开了「把实时路由同步到手机」、网络是否正常。超过 90 秒没有新快照就会显示离线。

## 网关与路由

**Agent 接入网关后连不上。**
到「网关」页看网关是否运行中；端口被占用时会在这里报错。再确认 Agent 选的模型所属的供应商已启用且设置了 key。

**路由组总是走备选。**
看「路由 › 最近决策」，展开「为什么这样选」，每个成员没被选中的原因（限流、鉴权失败、冷却中、未设置 Key……）都写在那里。

**我想关掉网关，恢复 Agent 原来的配置。**
关闭「设置 › 模型接入」时选「恢复原配置并关闭」，或者在「Agent」页逐个点恢复。

## 其他

**怎么切换英文界面？**
「设置 › 数据与帮助 › 界面语言」选 English，或者在首次启动引导右上角切换。英文界面还在逐页补齐。

**在哪里反馈问题？**
在 GitHub 的 [Issues](https://github.com/Geidorf/TokenLedger-open/issues) 提交，附上系统版本、TokenLedger 版本和复现步骤，请不要贴出 API key、账号或日志原文。安全问题按 [SECURITY.md](../../../SECURITY.md) 私下报告。
