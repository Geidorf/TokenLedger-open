# TokenLedger 用户手册

TokenLedger 是一本 AI 工具的 Token 账本：它读取你电脑上各个 AI 编码工具留下的日志，把 Token 用量、请求数和预估费用汇总成看板；可选地在本机起一个模型网关，让多个 Agent 共用供应商、按规则路由并自动记账；再可选地把汇总数据同步到你自己的云端，让手机和其他电脑也能看。

所有统计都先在本机完成。云端同步、模型网关、手机端都是可选的，默认关闭。

## 几个贯穿全书的口径

- **有效 Token = 输入 + 输出。** 缓存读取与缓存写入单独列出，不并入有效 Token，否则缓存会把总量放大几十倍。看板上可以切到「含缓存」视角对照。
- **预估费用**按本机价格表估算，带 `≈` 号；工具日志里自带的真实费用会优先使用。没有核价的新模型会进入「设置 › 模型价格」的待核价列表。
- **读不到就写不可得。** 额度、费用、账号维度读不到时显示「不可得」，不会用 0 顶替。
- **界面语言**：默认中文，可在「设置 › 数据与帮助 › 界面语言」切到 English。英文界面正在逐页补齐，尚未覆盖的页面暂时显示中文。
