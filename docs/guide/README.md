# TokenLedger 用户手册 · User Guide

- [中文手册](zh/README.md)
- [English guide](en/README.md)

手册面向使用 TokenLedger 的人：怎么安装、每个页面看什么、哪些数据会离开你的电脑。开发与构建说明见仓库根目录的 [README](../../README.md) 与 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

This guide is for people who use TokenLedger: how to install it, what each page shows, and which data leaves your computer. Build and contribution notes live in the repository [README](../../README.md) and [CONTRIBUTING.md](../../CONTRIBUTING.md).

配图说明 · About the screenshots: 桌面配图由 Playwright 打开开发版界面自动生成（`e2e/guide-screenshots.spec.ts`），Android 配图取自 Android 截图回归的参考图；画面里全部是示例数据，不含任何真实用户的数据。Desktop screenshots are generated by Playwright against the development build; Android screenshots come from the Android screenshot-test references. All numbers, device names and accounts in them are sample data.

重新生成桌面配图 · Regenerate the desktop screenshots:

```bash
TOKENLEDGER_GUIDE_SHOTS=1 npx playwright test --project=chromium-zh e2e/guide-screenshots.spec.ts
```
