# 桌面首次启动引导与无数据空状态（v1）

状态：实施中（2026-10-24 起，PR #57）。适用平台：桌面端主窗口。来源：维护者要求新装后有关键步骤引导，各页无数据时给出友好空状态。`docs/REQUIREMENTS.md` 与 `docs/DESIGN.md` 是单写文件，本文先记录行为事实，由其拥有者择机并入。

## 首次启动引导

**何时自动出现**：只在同时满足两点时自动打开，且每台电脑只自动打开一次：

- 本机账本已读到且为 0 行（`get_db_info.totalRecords === 0`；读不到或读取失败不算）；
- 本机 `localStorage` 里没有 `tokenledger.onboarding.v1`。

已有数据的电脑不会被打扰。「设置 › 数据与帮助 › 新手引导」与概览空状态里的「打开新手引导」随时可重新打开。

**四步**（状态全部由前端已有事实推导，不新增后端命令）：

| 步骤 | 完成条件 | 未完成时的动作 |
| --- | --- | --- |
| 扫描本机数据 | 本机账本行数 > 0 | 「扫描本机日志」，直接调用扫描 |
| 开启模型网关（可选） | 模型接入已开，`gateway_status` 报告已启用供应商 > 0 **且** `running` | 模型接入关：「开启模型接入」；没有启用的供应商：「添加供应商」跳供应商页；有供应商但网关没起来（如端口被占）：显示 `error`，「查看网关」跳网关页 |
| 开启云端同步（可选） | 已登录、数据连接已检查、首次同步完成 | 依次为「登录账户」「检查连接」（跳设置 › 云端账户）与「立即同步」 |
| 手机锁屏壁纸（可选） | `routing_publish_enabled` 已开 | 云端未就绪时不给按钮并说明先完成云端；就绪后「开启同步到手机」 |

网关状态只在引导可见且模型接入打开时读取，每 5 秒一次，窗口获得焦点时补读。

**显示状态**：`localStorage` 的 `tokenledger.onboarding.v1` 取 `open`（弹窗）、`minimized`（右下角进度胶囊「开始使用 n/4」）、`dismissed`（跳过）、`completed`（四步完成后点「开始使用」）。跳到其他页面完成某一步时自动收成胶囊；Esc、点遮罩与右上角关闭也是收起，不是跳过。胶囊上的关闭等于跳过。

**报错**：Toast 在引导遮罩之下，所以弹窗打开时 App 最近一条错误会在引导里重复显示一次。

**隐私**：引导只读本机记录数、模型接入开关、网关已启用供应商数与运行状态、云端登录与同步状态、手机路由开关；不读取任何订阅账号凭据（ADR-004）。

## 无数据空状态

共享组件 `src/components/EmptyState.tsx`（样式 `src/styles/onboarding.css`），三种版式：`card` 独立卡片、`inset` 嵌在已有面板里、`banner` 列表上方一行。每个空状态写清缺什么，并给出一个下一步：

| 页面 | 条件 | 下一步 |
| --- | --- | --- |
| 概览 | 当前范围无记录（原有结构，统一版式） | 扫描本地日志；打开新手引导 |
| 请求 | 本机账本为空且没有筛选 | 扫描本机日志（有筛选或只是范围为空时仍是「清除筛选」） |
| 会话 | 本机账本为空 / 只是所选范围为空 | 扫描本机日志 / 看近 30 天 |
| 额度 | 还没有任何额度快照 | 去设置授权（顶部「刷新额度」仍是立即读取的入口） |
| Agent | 没有可选模型 | 添加供应商 |
| 供应商 | 没有供应商 | 添加第一个供应商 |
| 网关 | 模型目录为空 / 最近请求为空 | 去添加供应商 / 去接入 Agent |
| 路由 | 没有路由组 | 有可选模型时「新建第一个路由组」，否则说明先启用供应商 |

## 预览

开发服务器地址加 `?fresh=1` 扮演刚装好的电脑（空账本、未登录、模型接入关、无供应商与额度），第一次扫描后示例账本出现；`?fresh=gateway` 相同但模型接入已打开。回归用例见 `e2e/onboarding.spec.ts`。
