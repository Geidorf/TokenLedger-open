## 0. 结论

**动态桌面没有废弃，但从没在真 Mac 上看过它长什么样。** 它只在 macOS 上存在：设置页「桌面壁纸」打开总开关、呈现方式选「动态桌面」后，Rust 在主显示器上建一个透明、点击穿透、位于系统壁纸之上与桌面图标之下的窗口，里面是 React 的 `LiveWallpaperView`；启动时与每次改壁纸设置时都会按设置显示或关闭它。Windows 用户在设置页看不到这个选项（前端按 UA 判定），Windows 只有静态图片壁纸和锁屏。代码里有两处死代码（§3）。T10.115（2026-09-06）重写后，交付日志写明“Mac锁屏，未覆盖安装或运行真实原生窗口验收”，验证状态至今是 `platform-pending`。所以准确的回答是：接线完整、功能在，真机效果未知；需要按 §3.3 的清单在一台 Mac 上看一次。

**最难看的五处**（全部清单见 §4）：

1. 桌面小组件就是托盘挂件原样搬上桌面：品牌行、44px 高的「今日/本周/本月」分段和 4 个图标的底栏常驻，外壳约占 440px 高度的四分之一；桌面上根本用不到这些控件（P1）。
2. 方盒子套圆角卡：桌面小组件窗口不透明、无阴影，Windows 和 macOS 上都是方窗口，16px 圆角卡片四角露出画布底色；托盘挂件在 Win11 上由系统画 8px 圆角，里面再切一层 CSS 16px 圆角，边角是两层（P2）。
3. 四种板式挤在同一个 340×440 窗口里：「单行消耗」只有两行数字，上下空出约三分之一高度，「额度总览」要滚动，「额度与用量」的“另有 N 个窗口”压在分隔线上（P3）。
4. 走势是直线段硬连、按窗口拉伸，毛刺明显，也没有昨日参照；动态桌面同样如此（P4）。
5. 动态桌面的灰色渐变面板在亮壁纸上撑不住：次要文字最差只有 2.47–2.96:1，工具名是 `codex`、`claude` 这样的小写 ID；它和桌面小组件、静态壁纸是三套互不相干的样子（P7、P8）。

另有一处必须修的口径问题：费用读不到时，挂件显示 `≈$0.00`，托盘提示和 macOS 菜单栏标题也是 `≈$0.00`，违反 GLB-01「不用 0 掩盖未知」（P6）。

**推荐方向 B「账本圆环」。** 把 Android 已经认可的 Ledger Rings（ADR-014、DESIGN §6.4）搬到桌面：托盘挂件、桌面小组件和动态桌面用同一套卡片；额度用圆环表示可用百分比，大号等宽数字，配色 B 只用于工具身份。理由有三条：

- 可读性：三个方向里只有 B 在两张示例壁纸、两种主题下文字全部 ≥4.5:1、图形全部 ≥3:1（§6.2）。代价是浅色必须用不透明白底，深色底最多透出 10%。
- 一致性：与 Android 小组件、主窗口 T10.150 令牌、20/50 阈值与配色 B 同一套语言，用户在手机和电脑上看到的是同一种东西。
- 不依赖原生特效：默认不透明也好看，Windows 不需要引入 Acrylic/Mica（那要改 `Cargo.toml` 的平台依赖，可能连带 lockfile），macOS 的原生模糊只是加分项。

**实施**分 7 块（§7）：先做不依赖真机的文案与口径修正（S，排在 T10.186 之后）；再做窗口外观、卡片组件与板式、按板式定窗口尺寸、悬停工具条（其中窗口部分要在真 Windows 和真 Mac 上验）；动态桌面换皮与删死代码必须先按 §3.3 在 Mac 上看过；静态壁纸与锁屏只做配色和口径，放在 T10.187 之后，可选。

**要用户拍板的 7 个问题**见 §9，每条带推荐。

## 2. 现状排查

### 2.1 托盘挂件

**接线。** `widget_window.rs:240–252` 建窗：340×440、不可缩放、无边框、置顶、不进任务栏；只在 macOS 上 `transparent(true)` 并施加 `NSVisualEffectMaterial::Popover`（圆角 16，失败时保留主题底色）；两平台都 `shadow(true)`。悬停/钉住状态机见 DESIGN §4.10（T10.110、T10.125、T10.136）。React 侧 `WidgetView` 按设置里的四种板式渲染（用量详情 / 额度与用量 / 额度总览 / 单行消耗），顶部是品牌 + 范围分段，底部是“读取于 hh:mm”+ 刷新、打开主窗口、打开设置、隐藏 4 个图标按钮。托盘提示文字与 macOS 菜单栏标题由 `tray_status_text` 生成（`widget_window.rs:759`）。

**平台差异。** Windows：不透明窗口，DWM 给无边框 + 阴影窗口画约 8px 系统圆角和 1px 边框（Tauri 文档对 `shadow` 的说明），CSS 卡片却是 16px 圆角，两层边角之间露出画布底色（推断，未在真实桌面上确认）。macOS：透明 + 原生 Popover 材质，理论上正常，未在真机上看过（T10.112 的 validation 仍是 `platform-pending`）。

**近期改动。** `b6e8cbb6` T10.105 首版 → `258b71a9` T10.110 悬停弹出与桌面小组件 → `116c4f2e`、`ee3a02fa` T10.112 原生材质、44px 控件、额度读取中与无数据分开 → `2cd2cf2f` T10.123 独立设置分区 → `4580b8a4` T10.124 按板式渲染、各读各的配置 → `e876f9f8` T10.125、`6891b06b` T10.136 悬停时序修复 → `a0bacfb3` T10.129 审计 10 条 → `da012802` T10.150 焕新（2026-09-24）。没有功能被删除或关闭。

**缺陷**（证据见 §4）：P1 应用外壳占比过高；P2 双层边角；P3 固定尺寸下的空白、滚动与压线；P4 折线毛刺；P5 同一来源的两个“每周”窗口同名（`WidgetView.tsx:142` 只取 `quotaWindowParts(window).label`，丢了分组名）；P6 「成本」「次请求」「请求」「剩余」等旧叫法，未知费用显示 `≈$0.00`（`format.ts:21` 把非有限值当 0；`widget_window.rs:768–778` 缺字段按 0），Rust 托盘的 `format_tokens` 与前端 `formatTokens` 规则不同（999,999 会写成 `1000.0K`，DESIGN §4.4 不允许）。

**本机验证不了的：** Win11 DWM 圆角与阴影的真实样子、macOS Popover 材质的真实观感、悬停弹出在真实托盘上的时序。

### 2.2 桌面小组件（Windows 与 macOS）

**接线。** `widget_window.rs:588–622` 建窗：340×440、无边框、`always_on_bottom(true)`（Windows `HWND_BOTTOM`，macOS `BelowNormalWindowLevel`）、不进任务栏、`shadow(false)`、`focused(false)`，**不透明、没有原生材质**。内容与托盘挂件是同一个 `WidgetView`，唯一区别是右下角“隐藏托盘挂件”换成“从桌面移除”。默认关闭；设置页开关、托盘勾选项、“从桌面移除”和直接关窗四条路径收敛到 `sync_desktop_widget`；拖动后 600ms 去抖记住物理像素位置，重建时中心点不在任何工作区就回到右下角。

**平台差异。** 两个平台的窗口参数完全相同，所以 macOS 上也是一块方窗口里套圆角卡片；macOS 上没有设置 `collectionBehavior`，推测只出现在创建它的那个桌面空间（Space），切到别的桌面就看不到（需真机确认）。

**近期改动。** 同 2.1（T10.110 引入，T10.124 起可单独配置板式、主题、默认范围与额度来源）。

**缺陷。** P1、P2 在这里最明显：常驻桌面的东西带着一整套应用控件，还是个方块；P3 同 2.1；浅色主题下是一块纯白方块压在壁纸上（P10）。

**本机验证不了的：** Windows 上 `HWND_BOTTOM` 窗口在「显示桌面」（Win+D）、虚拟桌面切换、多显示器下的表现；macOS 上 `BelowNormal` 层级与桌面图标、调度中心、台前调度、全屏应用的关系。

### 2.3 macOS 动态桌面

**接线。** 见 §3.1。设置页的布局预览直接复用 `LiveWallpaperView preview`（`WallpaperSection.tsx`），在 Windows UA 下不出现，在 Mac UA 下出现（截图 `settings-wallpaper-windows.png` 与 `settings-wallpaper-mac-ua.png`）。

**近期改动。** T10.115a/b/c（2026-09-06，`ce4a6850`、`c22fab14`、`5d32aaf5`、`d0bea9bb`、`779f8ef2`）：重写成中性半透明阅读层、分钟级时钟、事件驱动 + 5 分钟校准、原生窗口结果回传、静态模式不建窗口、清理不再碰 Dock 数据库。之后没有改动，T10.150 焕新也没有覆盖它。

**缺陷。** P4 走势是 `polyline` 直线段；P7 可读性；P8 细节：工具排行直接显示 `tool.name`（小写 ID），只给前三名的 Token 数、不给份额，没有工具色；「预估成本」「请求」是旧叫法（应为「预估费用」「记录数」）；64px 细体时钟和 1.39M 主数字抢同一层级。未知费用这里处理对了（显示「不可得」）。

### 2.4 静态壁纸与 Windows 锁屏

**接线。** `perform_wallpaper_update`（`commands/mod.rs:9276`）按设置渲染 PNG，Windows 用系统接口、macOS 用 AppleScript 设为壁纸；调度间隔桌面默认 60 秒（最小 15 秒）、锁屏 300 秒（最小 30 秒）。离线渲染 `examples/render_wallpaper.rs` 用 fixture 账本出了 1920×1080 的两张现状图。

**缺陷（P9）。** 用应用自绘的深色仪表盘整张替换用户自己的壁纸；时钟烘焙进图片，按 60 秒间隔最多慢 1 分钟；变化用红色胶囊（用量下降不是坏事）；颜色是苹果系统色（`APPLE_*`，T10.187 正改为配色 B）；「今日消耗 / 今日使用 … Tokens」「请求次数」是旧叫法；「较昨日 / 对比昨日」拿今天到此刻比昨天全天（`wallpaper.rs:648` 的昨日查询没有按当前时刻截断），与看板的「较昨日同期」不同口径（GLB-01：比较必须用同一桶定义）；读库失败的字段按 0 画（`unwrap_or(0)`）。有效 Token 口径是对的（`input_tokens + output_tokens`，`wallpaper.rs:631`）。

### 2.5 设置页两个分区

「桌面挂件」分区两张卡各有开关组与四项内容配置（板式、主题、默认范围、额度来源），**没有任何预览**，改板式看不到效果；「桌面壁纸」分区有布局预览，但只在 Mac UA 下出现（P12）。文案整体已按 T10.126 收紧，没有发现错误。

## 5. 三个方向

三个方向共用的内容规则（与现行 REQUIREMENTS 一致，只改呈现）：

- **用量详情**：有效 Token 大数字 + 较昨日同期；预估费用与记录数；24 小时走势（今日实线 + 面积、昨日虚线，单调三次曲线，00/06/12/18/24 刻度）；输入 / 输出 / 缓存（缓存标「单列」）；工具构成（前三 + 其他，配色 B 槽位色 + 工具显示名）；最紧的额度。
- **额度与用量**：最紧额度 + 有效 Token + 预估费用。**额度总览**：按吃紧程度排列，最多 6 个窗口，多出的写“+N”或“另有 N 个窗口”，不滚动；窗口名带分组（“Antigravity · Claude/GPT 每周”）。**单行消耗**：有效 Token + 预估费用。
- 额度一律写「可用 N%」，N = 100 − round(已用)，按显示值分档：≥50 充足、<50 偏紧、<20 告急（与 Android、看板一致）。
- 状态：读取中、无数据、历史快照（淡化 + “待刷新”与观测时间）、读取失败（虚线空槽 + “不可用”）、钉住的来源读不到（直说并给换源入口）、费用未知写「不可得」。
- 不放预测（REQUIREMENTS：托盘挂件与桌面小组件首版不放预测）。

### 5.1 方向 A「玻璃卡」

一句话：沿用主窗口 T10.150 的卡片语言，改成半透明原生材质上的一张安静卡片；四种板式保留，去掉应用式顶栏与底栏。

- 表面：深色 `rgb(22,25,32)` 72% / 浅色 `rgb(248,249,251)` 72%，叠在原生模糊（Windows 11 Acrylic/Mica、macOS `NSVisualEffectView`）上；圆角 20，1px 内高光。
- 额度用细横条 + “14% 可用 · 告急”；宽度保持 340，高度按板式（424 / 300 / 304 / 124）。
- 视觉稿：（视觉稿：方向 A 用量详情；图像存于内部仓库）；全套 `scratch/mockups/png/x1/dirA-*.png`（四种板式 × 深浅 × 两张壁纸、托盘挂件、动态桌面）。
- 优点：离主窗口最近，改动心智成本最低。缺点：72% 玻璃在花哨壁纸上撑不住小字和状态色（§6.2：深色三级文字与告急字 3.3–3.5:1，浅色 2.8:1，配色 B 图形最低 1.63:1）；要么提高到接近不透明（就不是玻璃了），要么靠原生材质的实际模糊强度，而 Windows 要为 Acrylic 把 `window-vibrancy` 从 macOS 专用依赖扩到 Windows（改 `Cargo.toml`，可能连带 lockfile，都是单写文件），Acrylic 在拖动窗口时还有已知的性能问题。

### 5.2 方向 B「账本圆环」（推荐）

一句话：把 Android 已认可的 Ledger Rings 搬到桌面：固定尺寸的小组件卡片、近不透明底、圆环表达额度、大号等宽数字，托盘挂件与桌面小组件共用同一套卡片。

- 表面：深色 `#0E1116`，允许 90%（透出 10% 模糊壁纸）；浅色 `#FFFFFF` **不透明**。圆角 22（桌面小组件、动态桌面 28）。
- 额度用圆环：环 = 可用百分比，环心只放数字，来源与“窗口 · 档位”写在环外（DESIGN §6.4 的规则）。
- 窗口尺寸按板式（§6.4）；桌面小组件不带任何常驻控件，悬停才出现工具条；托盘挂件顶部一行放范围分段与 4 个图标。
- 视觉稿：（视觉稿：方向 B 用量详情；图像存于内部仓库）、（视觉稿：方向 B 额度板式；图像存于内部仓库）、（视觉稿：方向 B 动态桌面；图像存于内部仓库）；全套 `scratch/mockups/png/x1/dirB-*.png`。

### 5.3 方向 C「极简字排」

一句话：桌面上不放卡片：数字像锁屏时钟一样直接排在壁纸上，只靠柔边暗场保证可读；托盘挂件改成一张带点线引导的「账单小票」。

- 表面：桌面上是羽化暗场（深色 `rgb(8,10,14)` 58%）或亮场（白 62%），没有卡片边界；托盘挂件是不透明小票（`#1D2129` / `#FFFFFF`），点线引导 + 等宽数字。
- 视觉稿：（视觉稿：方向 C 用量详情；图像存于内部仓库）；全套 `scratch/mockups/png/x1/dirC-*.png`。
- 优点：最像“壁纸的一部分”，最轻。缺点：可读性完全看壁纸（§6.2，拖到风景壁纸最差处：告急字 2.1–2.2:1、浅色次级文字 3.6:1、工具色 1.2–1.4:1）；没有卡片就没有拖动与悬停的落点；额度状态只能靠彩色字，与 Android 圆环不一致。小票式托盘挂件本身可读性很好，可以单独借鉴。

## 6. 推荐：方向 B「账本圆环」

### 6.1 理由

1. 唯一在两张示例壁纸、两种主题、任意摆放位置下文字 ≥4.5:1、图形 ≥3:1 的方向（§6.2）。
2. 与 Android 小组件、主窗口令牌、额度阈值与配色 B 是同一套语言；「Mac 的小组件」和手机上的小组件长得一样。
3. 结构问题一并解决：外壳挪到悬停；按板式定尺寸，去掉空白与滚动；额度改圆环、窗口名带分组。
4. 默认不透明就成立，不押注 Acrylic/Mica 或 macOS 材质的实际效果；原生模糊只是深色的加分项。
5. 动态桌面直接复用同一张卡片的放大版，三块表面终于是一家人。

### 6.6 桌面小组件的交互

- 平时没有任何按钮。指针移入时在右上角淡入工具条（120ms，减弱动效时直接出现）：刷新、打开主窗口、设置、从桌面移除；工具条出现时盖住“更新于”，不盖大数字。
- 除工具条外整张卡片是拖动区（`data-tauri-drag-region`）。
- 桌面小组件不可聚焦（`focused(false)`），键盘用户通过托盘菜单与设置页完成同样的操作（现状已具备）。
- 范围固定为设置里的默认范围，桌面上不放范围分段；要临时看本周或本月用托盘挂件。

### 6.7 动态桌面阅读层

内容严格按 GLB-09：时间（64px/300）与日期；“今日 · 有效 Token”与来源（本机 / 云端）；50px 大数字 + 较昨日同期；预估费用、记录数；走势（今日 + 昨日虚线）；输入 / 输出 / 缓存（单列）；工具构成（显示名 + 配色 B + 份额）；底部“本机 · 数据生成于 · 读取于”。历史快照时胶囊换成“历史快照 · 7月14日”。不放额度与预测。只做深色一版（与现在一致）。

### 6.8 静态壁纸与锁屏（可选）

只做三件事，不改版式：配色 B（随 T10.187）；变化胶囊改中性色、写「较昨日同期」并把昨日查询截到当前时刻；「有效 Token」「记录数」叫法。是否把静态壁纸改成 B 卡片叠在用户原壁纸上（需要读取用户当前壁纸文件）另议（§9 Q5）。
