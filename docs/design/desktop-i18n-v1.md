# 桌面界面英文（i18n）v1

适用平台：桌面（Tauri 前端）。状态：第一批已实现，其余页面逐页迁移。

## 做法

- 文案表在 `src/i18n/`：`zh.ts` 是中文原文，也是键的唯一来源；`en.ts` 用 `Record<MessageKey, string>` 声明，缺键或多键时 `npm run typecheck` 直接报错。不引入第三方 i18n 依赖。
- 键按页面分组（`onboarding.*`、`empty.*`、`language.*`…），占位符写成 `{name}`，中英两边必须一致。
- 组件里用 `const t = useT(); t('key', { count })`；纯函数（例如引导步骤推导）接收 `lang` 参数，调用方用 `useLang()` 取当前语言并把它放进 memo 依赖。数字用 `formatCount(n, lang)`，跟随界面语言分组。
- 一个文件里有很多小组件时，也可以直接用模块级 `t()`，再在页面根组件调用一次 `useLang()` 订阅语言变化（路由页、网关页这样做）；`memo` 过的子组件要自己调用 `useT()` 或 `useLang()`。
- 模块级标签表（`STATUS_LABEL[code] ?? code` 这类）用 `localized({ code: 'key' })` 生成，每次读取都取当前语言。
- 语言偏好：`中文`（默认）、`English`、`跟随系统`，在「设置 › 数据与帮助 › 界面语言」和首次启动引导右上角切换，立即生效，存在本机浏览器存储 `tokenledger.lang.v1`，不进同步设置。地址带 `?lang=en` 等同于选 English（截图与回归用）。
- 默认仍是中文：英文没覆盖全部页面前，英文系统的新安装不自动切到半中半英的界面。全部页面迁完后再把默认改成「跟随系统」。
- `<html lang>` 随界面语言切换，读屏按对应语言朗读。

## 已迁移

- 第一批：首次启动引导（对话框、右下角进度胶囊、四个步骤的状态文案）、设置里的「新手引导」与「界面语言」卡片，以及 Agent、供应商、会话、额度四个页面的无数据空状态。
- 第二批：路由页（路由组卡片与编辑器、权重、规则、会话保持、冷却、实时路由动画与说明句、最近决策与决策解释链）、网关页（状态、接入示例、模型目录、最近请求）、复制按钮，以及请求展开行与用量概览里的 Context 构成。
- 第三批：顶栏（导航、扫描与同步按钮、云端状态、壁纸与战报入口）、页头（数据范围、设备、主题菜单）、用量子页名称，以及设置里的「手机动态壁纸」「其他电脑的共享用量」两张卡片。`tests/frontend-contracts.test.mjs` 里针对这些文件的源码断言改为检查键名与 `zh.ts` 中的中文原文。
- 第四批：请求明细列表（筛选、汇总、表头、展开行、复制 Session ID）、时间范围控件与自定义日期弹层、多选筛选、数据粒度标签。看板「选择预设范围」把焦点移到范围控件时改用 `data-range-control` 定位，不再依赖会随语言变化的无障碍名称。
- 第五批：设置里的预算提醒、外部网关 WebDAV 同步、按项目统计三张卡片，以及设置通用组件（开关保存中提示、默认的「权限与数据边界」「危险区」标题）。外部用量导入卡片的文案含第三方产品名，暂保持中文。
- 第六批：供应商健康度（徽标、24 小时趋势、详情区）、供应商页（列表、编辑表单、预设分组、确认框与提示）、Agent 页（模型选择、配置改动预览、恢复、手动配置面板）。手动接入的 Agent（Cline、Claude Desktop）步骤说明随后也已迁入。

后端（Rust）返回的文字，例如决策的 `detail`、错误信息，仍是中文，后续单独处理。

## 迁移一个页面

1. 把页面里的中文抽到 `zh.ts`，在 `en.ts` 补英文；机器字段、Provider 名、用户自定义名称保持原文（同 REQUIREMENTS 的额度命名规则）。
2. 页面整份迁完后把文件加进 `src/i18n/messages.test.ts` 的 `FULLY_LOCALIZED`，此后这个文件里再写死中文会让单元测试失败。
3. 在 `e2e/english.spec.ts` 补英文断言；画面有意变化时按 `e2e/README.md` 重新生成截图基线。

## CI 检查

`src/i18n/messages.test.ts` 随 `npm run test:unit` 在 CI 里跑：中英键一一对应、文案非空、占位符一致、英文里没有漏翻的中文、每个键都有代码在用、已迁移文件里没有写死的中文。
