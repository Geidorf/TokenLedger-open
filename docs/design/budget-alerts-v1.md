# 预算与超支提醒（v1）

状态：桌面端已上线（2026-10-24，PR #70）；手机通知实施中。适用平台：桌面端（设置 › 预算提醒、系统通知、托盘提示）；Android 经 `docs/contracts/budget-snapshot-v1.md` 读取预算状态并推本地通知。来源：用户要求按日 / 周 / 月、按 Agent / 模型 / 账号设费用或 Token 预算，接近或超出时提醒。

## 不做的事

- **不外推**：只看已经发生的用量，不按速度预测「月底会超」。预测类提醒等外推口径解禁后另做。
- **规则不进云端**：预算规则与提醒去重状态只存在本机应用数据目录（`budget_settings.json`、`budget_alert_state.json`），不改 `StatsData`。打开「同步到手机」后只上传脱敏的状态快照（范围名、周期、整数百分比、级别，见 `budget-snapshot-v1`），不上传金额与上限。
- **不读订阅凭据**：账号维度只来自网关自己记下的转发目标（`dashboard-stats-v2` §2.7 的 `providers`）。
- **额度窗口提醒不重复做**：额度窗口剩余 50% / 20% / 5% 的系统通知已在「订阅额度 › 额度提醒」（REQ-QUOTA-07），预算只管本机账本里的费用与 Token。

## 规则

| 字段 | 取值 |
| --- | --- |
| `period` | `day` 今日 · `week` 本周（周一起） · `month` 本月；与看板的 `today` / `week` / `month` 范围同一日历边界 |
| `metric` | `cost` 预估费用（美元，与看板费用同值） · `tokens` 有效 Token（输入 + 输出，缓存不并入） |
| `scopeKind` / `scopeId` | `all` 全部 · `tool` 某个 Agent · `model` 某个模型 · `provider` 某个账号（网关供应商名） |
| `limit` | 大于 0；Token 取整且至少 1 |
| `warnPercent` | 50–99，默认 80；界面给 50 / 70 / 80 / 90 |
| `enabled` | 停用的规则不计算、不提醒 |

最多 32 条。读到不合法的规则只丢这一条，其余照常。

## 读数

每次计算按规则用到的周期各取一份本机统计（`get_stats_impl`，在后台线程里聚合，不阻塞界面），从同一份数据读：全部用 `summary.totalTokens` / `summary.totalCost`，分组用 `tools` / `models` / `providers` 里该键的 `total` / `cost`。

- 分组里没有这个键：本周期没有用量，记 0。
- 费用为 `null`（有未核价记录）、负数，或账号维度缺失（没有网关账本）：**不可得**，不当成 0，也不提醒。

级别：`used >= limit` 为超出；`used * 100 >= limit * warnPercent` 为接近；其余正常。

## 提醒

- 触发时机：每次刷新托盘提示时（后台扫描写入新记录、手动刷新、跨日、保存预算设置），另外有预算时每 5 分钟检查一次，这样只经网关的用量也能及时提醒。
- 每条规则每个周期「接近」与「超出」各一次；直接跳到超出时只发一条超出，接近档同时记为已发。改了周期、范围、口径或上限都视为新预算，重新计数。
- 全局每小时最多 4 条；被限流的提醒不记为已发，下次检查再送。排序先超出、再按已用比例从高到低。
- 系统通知总开关默认关闭；关闭时仍计算，设置页与托盘照常显示。
- 通知只写范围名、周期与百分比，例如「Codex 预算已用 85%」「本月费用预算已用 85%」，不写金额、路径或账号细节；含 `/ \ @ : $` 等字符或过长的名字退回「账号」「模型」等通称。
- 托盘提示在原有一行后追加「预算：1 项超出 · 2 项接近上限」，没有接近或超出的预算时不追加。

## 同步到手机

- 「设置 › 预算提醒 › 同步到手机」，默认关闭；打开后每次预算检查后发布快照（内容没变就不发，至少每 30 分钟心跳一次），关闭时删除本机快照。
- 开关下方说明当前状态：已同步（最近一次时间）、需要登录云同步、云端尚未部署、同步失败（原因）。
- 手机端读取与通知规则见契约 §5。

## 命令

`get_budget_settings`、`set_budget_settings`（规范化后写入并立即刷新托盘）、`get_budget_status`（各规则的 `used` / `limit` / `percent` / `level` / `periodStart`，本月出现过的 Agent、模型、账号作为输入建议，以及 `phoneSync` 同步状态）。只授予主窗口。
