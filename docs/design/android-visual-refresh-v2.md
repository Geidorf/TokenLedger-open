## 0. 一页结论

**方向：同一本账，原生表达。**

1. **同一套材质。** Android 用桌面 T10.150 的四档纵深（外壳 → 页面 → 卡片 → 浮层）、海军蓝中性色、1dp 发丝边与极淡环境光；品牌渐变只做身份（品牌块、导航选中、主卡光晕），数据只用 `chart-1…8`，状态色只表状态。
2. **数字领衔，颜色退场。** 每屏一个主数，等宽数字，层级靠字号与色阶（400 / 500 / 600），数字一律主文字色；变化、费用、缓存不再染色；顶栏、范围与页签收成紧凑的两行，首屏留给数据。
3. **原生骨架。** Material 3 组件、edge-to-edge、48dp 触达、TalkBack 语义优先；320dp + 字体 200% 靠重排而非截断；动效只有挂载一次的揭示、滑动选中与按压，系统关动画、墨水屏时全部退化为瞬时。

**两项待决的定值：**

- **#237「Android 挂件与正文共用同一套配色」——单一色源。** 以应用色板的角色集为准，新建 `ui/foundation/LedgerTokens.kt` 作为唯一色源，取 §3.1 的新值；`v2Palette`、M3 `ColorScheme`、小组件 `WidgetColors`（含圆环位图 ARGB）、海报预览色板与 `res/values*/colors.xml` 全部从它派生，不再各抄一份。分隔线拆成两个角色：**`divider`（装饰发丝线，约 1.2:1，只能与间距、对齐或标题一起出现，不得单独承担边界）**与 **`outline`（功能边界，对页面、卡片、内嵌块、浮层都 ≥3:1）**；墨水屏两者都是纯黑。
- **#235「Android 排版间距落在 2px 栅格上」——间距栅格。** **4dp 基础栅格；2dp 半格只能经命名令牌 `LedgerSpace.hairline` 使用**（标签贴数值、图标贴文字、热力格间隙）。现存 6/10/14/18/22/26 在各组件重写时按 §3.6 映射归位，不做盲目全局替换。当前契约拦下的三处越格直接定值：状态徽标圆点 5.5dp → 6dp（内边距 7×3 → 8×4、间距 4.5 → 4）；日历格 `padding(1.dp)` 取消，改为 10dp 格 + 2dp 间隙；图表读数行距 1dp → 2dp。

**实施（§8）：** A0 令牌、主题与原子组件先行（依赖 T10.166 的契约取源搬迁合入），之后 A1 导航壳、A2 今日、A3 图表与读数、A4 额度、A5 来源 / 明细 / 专属看板、A6 日历、A7 展示与摆件、A8 分享海报、A9 小组件、A10 设置与登录；T10.172 的 C1–C10 按同文件原则并入或排在对应任务之前（§8.2）。

## 2. 设计方向

### 2.1 推荐方向：同一本账，原生表达

桌面 T10.150 解决的是「处处加粗、框中套框、平灰无纵深、颜色不表意、动效零散」。Android 的病是同一批，所以药方同源：**同一套令牌与语义**，但**用 Android 自己的骨架表达**——M3 顶栏、底部导航胶囊、底部面板、系统返回、edge-to-edge 与 TalkBack，而不是把桌面网页缩小。

六条原则：

1. **四档纵深。** `chrome`（底栏 / 侧轨）→ `page`（页面，顶部叠极淡的品牌环境光）→ `card`（卡片，1dp 发丝边；浅色加短柔阴影）→ `popover`（面板、菜单、读数气泡，浮层阴影）。卡片内部分组用 `raised` 填充或发丝线，不再画带边小卡片。
2. **颜色只说意思。** 品牌渐变 `brand1 → brand2` 只用于：顶栏品牌块、底部导航选中胶囊、主卡左上光晕、登录页标识。数据系列只用 `chart-1…8`；成功 / 警告 / 危险只表达状态；数字、费用、变化值一律主文字或次级文字色（T10.154 §4.1、T10.156 §2.4）。
3. **层级靠字号与色阶，不靠字重。** 正文 400；标签、按钮、导航、分段 500；标题与数字 600。系统中文字体在多数机型上只有常规与粗体两档（500 显示为常规、600 显示为粗体），与桌面 Windows 同一处境，所以其余位置不加粗。
4. **少一层框，少一行框架。** 查询摘要并入顶栏副标题并兼作筛选入口；范围分段永远一行（放不下就横向滚动）；大按钮降为卡内行动行。
5. **动效只解释状态变化。** 挂载时揭示一次，后台刷新不重播；选中态滑过去；按压即时回弹；读数气泡从触点弹出。系统「移除动画」、动画倍率 0、墨水屏时全部瞬时完成。
6. **诚实优先于好看。** 未知值是「不可得」加虚线空槽或斜纹空档，绝不画成 0 宽的条或 0 高的点；历史数据带时钟与观测时间并淡化；预测永远带可见的「预测」标签。

### 2.2 为什么不选另外两条路

| 备选 | 不选的理由 |
|---|---|
| M3 动态取色（Material You，随壁纸变色） | 图表系列色、额度分档色与桌面同一身份会随壁纸漂移，对比度无法事先证明；四端统计口径一致之外，视觉身份也要一致 |
| 毛玻璃 / 大面积模糊 | `minSdk 26`，`RenderEffect` 要 API 31；低端机与墨水屏代价高，且会降低数字对比度 |
| 在现有样式上继续打磨 | 用户明确要求「视觉要大改造」；D1–D14 多数是体系问题，局部打磨已做过 T10.130–T10.138 多轮 |

- **`res/values*/colors.xml` 与 `styles.xml` 只保留启动窗口需要的底色**，深色等于 `page`（`#0D0F13`）；浅色刻意也取深色页面色 `#0D0F13` 而不是 `#F4F5F7`，避免冷启动白闪（T10.95 回退，XML 注释写明，T10.177），`colorAccent` 等于 `primary`；由 JVM 测试比对 XML 与 `LedgerTokens`。
- **分隔线规则（#237 的第二半）。** `divider` 是装饰性的，WCAG 1.4.11 不要求它 ≥3:1，但**只允许出现在「边界已由别的方式表达」的地方**：卡片边（卡片本身有底色差与圆角）、同一列表内的行分隔（行高 ≥48dp 且内容左对齐）、图表网格、卡内分组（组间距 ≥12dp 或有组标题）。凡是线条是唯一线索的地方（输入框、复选框、未知值虚线槽、日历覆盖外格、焦点、墨水屏的全部分隔），一律用 `outline`（≥3:1）。`MobileV2PaletteContrastTest` 恢复为：`outline` 对 `page / card / raised / popover` 全部 ≥3:1；`divider` 在深浅色落在 1.1–2.0:1（既不隐形也不变粗）；墨水屏两者 = 纯黑。

### 3.6 间距栅格定值（#235）

**决定：** 4dp 基础栅格，2dp 半格只能经 `LedgerSpace.hairline` 使用。理由：桌面 `--space-1…` 是 4px 栅格；T10.79 原型定的是 2/4/8/12/16/20/24/32；M3 也是 4dp 栅格。

## 4. 组件规格

### 4.1 顶栏（`V2TopBar`）

- 64dp 高，内容左 16、右 4；背景 `page`，内容滚到其下方时切为 `chrome` 并出现底部 1dp `divider`（`FAST`）。
- 左：28dp 品牌块（`brand1 → brand2` 135° 渐变、圆角 8、白色 16dp 账本层叠图形；读屏忽略），间距 12；标题 `titleL`；副标题 `meta` `faint` = 查询摘要（「全部设备 · 更新于 14:30」），后跟 14dp 下拉箭头。**副标题就是筛选入口**：整块（标题 + 副标题，≥48dp 高）点按打开筛选面板；有筛选生效时摘要写出条件（「2 台设备 · codex」）并在箭头旁加 6dp `primary` 圆点。长摘要可展开读全文。取消「TOKENLEDGER」眉题与单独的查询摘要行。
- 右：48dp 图标按钮（24dp 图标，`muted`）：分享（今日、复盘；T10.172 Q6 推荐保留顶栏分享）、刷新（进行中 `SPIN`）、设置。额度页只有刷新与设置。最多三个图标，320dp 下不挤标题。
- 专属看板：左侧返回箭头替代品牌块，标题前 10dp 身份色点，副标题为面包屑「复盘 · 来源 / codex · 今日 · 全部设备」。
- 纵排模式（§6.2）：隐藏品牌块，副标题下移为顶栏下方独立一行，可换行，不截断。
- 查询范围切换或后台刷新时，顶栏保留固定高度的状态槽，短暂刷新只显示底边进度条；正常、刷新和稳定状态之间切换不得改变顶栏测量高度或推动范围控件及内容。离线、过期及错误的稳定状态仍显示文字，完整刷新状态由 TalkBack 读出（T10.217）。

### 4.2 底部导航与侧轨（`V2NavigationBar` / `V2NavigationRail`）

- 容器 `chrome`，顶部 1dp `divider`；80dp + 系统手势区。四项：今日 / 复盘 / 额度 / 展示。
- 选中：64×32 指示胶囊填 `brandSoft` 横向渐变（墨水屏为黑胶囊白图标），图标 `primary` 且切换为实心变体，标签 `text` `labelS`；未选中：线框图标与标签均为 `faint`。
- M3 `NavigationBarItem` 的指示器只接受纯色、且每项各自淡入，做不到「一个胶囊滑过去」：实现上与分段控件共用一套自绘指示器（测量各项位置，单个胶囊用 `INDICATOR` 移动），读屏树仍是标准的 tab 语义；做不到时回退为 M3 纯色 `primaryContainer` 指示器。
- 宽度 ≥ 600dp 或横屏：`NavigationRail`，容器 `chrome`，右侧 1dp `divider`，顶部放品牌块，项目同上。

### 4.3 分段控件（`V2SegmentedToggle`，范围与复盘页签）

- 轨道：`raised`、圆角 12、内缩 4、高 48（随字体放大：`max(48, 文字行高 + 16)`），无边框（墨水屏 1.5dp 黑边、白底）。
- 选项：`label` `muted`；选中项文字 `onSelected`，并带 1dp `primary` 描边（墨水屏除外，R-18）；背后是一枚**滑动胶囊**：`selected` 底、圆角 8、浅色加 1dp 短阴影、深色加 1dp 顶部内高光，`INDICATOR` 动效在选项间移动。每项仍是 `Role.Tab` 或单选语义，带 `selected` 与状态描述（契约「Android dashboard range and insight selectors expose one selected radio option」保留）。
- **永远一行：** 范围轨道按内容取宽（每项最小 48dp），放不下时整条横向滚动，溢出侧 28dp 渐隐，选中项自动滚入视野；复盘页签等分宽度，放不下时同样横向滚动。不再折成两行。宽度按最宽文案推出，调用点不写死（契约「Android 分段控件按最宽文案定宽，调用点不写死」）。等分宽度的轨道里文字放不下时，依次把左右留白从 8dp 收到 4dp、逐级缩字到 11sp；仍放不下才折两行，现行生产界面走不到这一步（T10.177 R-31、R-35）。在 320dp × 200% 下引入五段分段控件的任务须让轨道随两行文字长高（契约的轨道高度改为最小高度），不得截断或出省略号（R-40）。
- 「自定义」是轨道右侧 8dp 外的 48dp 方形按钮（`raised`、圆角 12、日历图标）；自定义生效时胶囊离开轨道、按钮切为 `primaryContainer` + `primary` 图标，副标题写出具体日期。
- 墨水屏：胶囊为黑底白字，无动画。

### 4.4 卡片与分区

- 标准卡：`card`、圆角 16、内边距 16、卡间距 12、页边距 16（≥600dp 为 24）；纵深见 §3.3。

- **明细表：** 列「时段或日期 / 本期 / 同期 / 箭头」，`tnum` 右对齐，行高 ≥40，行分隔 `divider`；默认最近 3 行，标题行右侧「展开全部」；**每行可点**并带动作说明，进入该时段或该日明细（T10.172 P2-9 的读屏路径）。

- **构成条：** 8dp 高、全圆角、段间 2dp 间隙；每段颜色与下方图例点一致；未知部分不画段，以「未计入：不可得」说明。
- **动画：** 首次挂载 `CHART_REVEAL`；用户切换指标或范围后 `CHART_UPDATE`；后台刷新直接画新数据；关动画时直接画终态。

### 4.9 额度：条、环与状态

- **一个整数槽，三端同一分档：** 所有表面（今日卡、额度页、摆件、小组件、读屏）显示同一个整数「可用 = 100 − round(已用)」，并**按这个显示值**分档：≥50 充足、<50 偏紧、<20 告急（T10.172 P1-1 与 Q2 推荐项；D4 阈值不变）。避免「显示 20%、却画成告急色」。
- **颜色：** 充足 = `primary`，偏紧 = `warning`，告急 = `danger`；三端一致（桌面 `QuotaPanel` 已是蓝 / 琥珀 / 红，本方案把 Android 应用的「充足 = 绿」改为蓝，小组件保持蓝）。
- **数字不染色：** 百分比 `numM`（额度页）/ `numS`（概览、小组件）`text` 色、`tnum`，后跟 `caption`「可用」。
- **一行写完状态：** 窗口标签（「每周额度」「Codex · 每周」）始终在标题行，不被状态词替换；元数据行 = 档位词 · 重置时间（· 历史数据），档位词偏紧用 `warningText`、告急用 `dangerText` 并前置 14dp 警示图标，重置时间 `faint`。这延续契约「Android 额度行副标题写窗口，不复述状态词」与「Android 额度窗口的重置与状态合成一行」的意图；档位由文字说出，颜色不再是唯一线索，原先告急档的 1dp 描边可以取消（契约 #238 随之改写）。
- **条：** 额度页 8dp、概览 6dp、全圆角；轨道 `raised`；填充从左生长（`GROW`）。墨水屏：白轨道 + 1dp 黑内描边、黑填充；告急再加斜纹。
- **历史数据：** 条仍按档位着色，但填充 45% 不透明（「不是现在」）；元数据行前置时钟图标 +「历史数据」（`warningText`）+ 观测时间「07-15 12:40」（额度页外层只写到分钟，完整时间戳留在详情，契约「Android 额度页外层只写到分钟，完整时间戳留在详情」）。
- **不可用 / 错误 / 需授权：** 不画条、不画 0；位置放 `outline` 1dp 虚线空槽 + 原因文字 + 恢复动作（「去设置授权」「重试」）。
- **速度（T10.153 §5.2，逻辑见 T10.172 C7）：** 每个百分比窗口下一行「[预测] 照此速度，重置时约用 60%」；语气：中性 `muted`、警示 `warningText`、危险 `dangerText`；速度行不复用充足 / 偏紧 / 告急等级词；历史、已用完、不支持时不显示。「预测」标签见 §4.6。
- **来源标识：** 两字母块（Cx / Cl / AG，`raised` 底、`labelS` 600 `muted`），不用厂商标志或厂商色。
- **圆环（小组件、摆件）：** 直径沿用 DESIGN §6.4（2×2 40dp、4×2 58dp、单来源 72dp），线宽约为直径的 10%、圆头；轨道 `raised`；中心只放百分比（`numS` 600）；Provider 名与「窗口 · 档位」在圆环**下方** 8dp 处，两行居中（修 D13）。

## 5. 动效规则

1. **只在挂载时揭示一次。** 切一级页、切复盘页签、打开面板、首次加载完成时播放；后台刷新、轮询、同一查询的数据返回不重播（DESIGN §4.4、T10.156 §6.3）。揭示状态用 `rememberSaveable` 记「已播放」，键 = 目的地 + 页签，不含数据版本。
2. **后台刷新立即完成。** 数值、条宽、重排都直接到新值；只有用户主动改变查询、指标或档位时才用 `UPDATE` / `CHART_UPDATE`。
3. **选中态滑过去，不跳过去：** 分段胶囊、导航胶囊用 `INDICATOR`；首帧落位不滑。
4. **数据相关的元素不用回弹曲线**（阻尼比 < 1 的弹簧只留给底部面板这类系统手势）。
5. **数字只做交叉淡入，不逐帧数数；首次渲染直接给真值。**
6. **关闭条件（任一满足即全部瞬时）：** 系统「移除动画」或 `ANIMATOR_DURATION_SCALE == 0`；墨水屏主题；摆件在省电或过热（`thermalStatus ≥ MODERATE`，沿用 `resolveLowPowerPolicy`）时。瞬时 = 时长与延迟压成 0，直接到终态；无限循环（`LIVE`、`SPIN`、骨架呼吸）不启动，改为静态文字状态。
7. **动画倍率：** Compose 的 `tween` 会随开发者选项的动画倍率缩放，所以错开与延迟必须写成 `ledgerTween(delayMillis = …)`，不用协程 `delay()`（手写的等待不会被缩放）。`systemAnimationsEnabled()` 目前用 `remember(context)` 只读一次，A0 改为在 `ON_RESUME` 时重读，用户在系统设置里改完回到应用即生效。

## 6. 无障碍

### 6.1 TalkBack

- 顶栏标题为 heading；副标题整块是按钮：「查询：今日，全部设备，14:30 更新。双击调整筛选」。
- 导航项：「今日，已选中，第 1 项，共 4 项」；选中同时有实心图标这一非颜色线索。
- 分段：`selectableGroup` + 每项 `selected` / 状态描述；滚动轨道里的离屏选项仍可被读到。
- 主数块合并为一个节点：「有效 Token 1.28M，较昨日同期增加 12.4%，输入 920K，输出 360K」；口径芯片是 Switch 语义。
- 图表：一个摘要节点（范围、本期与同期、峰值、不可得的桶）+「查看数据表」动作；明细表每行是可点击节点并带动作说明；读数以 Polite 播报。
- 额度窗口：「Codex 每周额度，可用 38%，偏紧，4 天后重置」；历史写「历史数据，观测于 07-15 12:40，可能已变化」；速度行读「预测：照此速度，重置时约剩 10%」（T10.153 §5.2 的 `ariaLabel`）。
- 日历：每个月是一个节点，读「3 月：合计 1.2M，活跃 18 天，最高 9 日。双击选择日期」（T10.172 C9）；当前查询范围与覆盖外在月摘要里说出来。
- 隐藏费用：「预估费用已隐藏，双击显示」（T10.154 §4.11）。

### 6.2 字体 200% 与 320dp（纵排模式）

触发：可用宽度 < 360dp 或 `fontScale ≥ 1.5`。

- 顶栏：隐藏品牌块，副标题下移独立成行，可换行；图标按钮不变。
- 范围与页签：一行横向滚动，轨道高度随字增高。
- 主数块：主数、变化行、副行、费用块自上而下纵排；数字仍不换行，按 §3.7 降档；所有标签可换行不截断。
- 行：「名称 / 数值 / 箭头」三列改为名称一行、数值一行，箭头贴右上。
- 次级指标条：改为纵向「标签在左 · 数值在右」行（DESIGN §6.2 的 T10.134 规则）。
- 展示页页签与额度胶囊：不截断，换行或滚动；「额度墙」「Codex 订阅」必须完整可见；金额放不下时整体降档，绝不截成「¥132.4」（修 D9）。
- 验收：320×844 与 390×844 在 200% 下无截断、无重叠、无小于 48dp 的触点（示意图 `overview-320-font2`）。

### 6.3 其他

- edge-to-edge：`Scaffold` 消费 `WindowInsets.safeDrawing`（沿用）；页面环境光与顶栏画到状态栏下面，底部导航承接手势区；横屏时 `NavigationRail` 承接左侧 `displayCutout`；登录页消费 IME insets。

## 7. 分屏方向

内容组成随 T10.172 的结论与用户对 Q1–Q8 的回答调整；以下规定每块的**视觉形态与位置**，槽位数量是弹性的。

### 7.1 今日
