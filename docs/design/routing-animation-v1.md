# 网关路由实时动画（v1）

状态：实施中（2026-10-23 起）。适用平台：桌面端主窗口（已做）、托盘弹层与桌面小组件（下一步）、Android「路由」页与动态壁纸（复用本文的场景结构）。来源：用户要求网关路由页做实时舞台：Agent → 网关 → 供应商/账号，请求实时流动，失败时可见地切到下一个。

## 不做的事

- **不造假**：没有可靠数据源时显示空态，不播放示意动画。动画里的每一条流都对应一条真实记录。
- **不做锁屏帧动画**：Windows 与 macOS 锁屏不支持逐帧动画；桌面端只在主窗口、托盘弹层和桌面小组件里动。Android 动态壁纸另行实现。
- **不展示敏感内容**：不显示会话 ID、账号名、密钥、错误正文；只显示 Agent 名、`供应商/模型`、状态码。

## 数据源

| 来源 | 读法 | 能画什么 | 注意 |
| --- | --- | --- | --- |
| TokenLedger 自带网关 | `gateway_status`、`gateway_recent_route_decisions`、`gateway_recent_requests`，主窗口每 1.5 秒轮询，页面隐藏时暂停 | 组请求的每次尝试（失败、拒绝、跳过、接通）；直连请求在结束后出现 | **RouteDecision 在上游开始回包时就记下**，流式请求此刻还没结束，所以接通只算 `routed`（已接通），不算完成。Agent 名从账本按 `logicalRequestId` 关联，取不到就写「Agent」。 |
| 外部本机网关 | 外部网关实时快照命令（契约在 `docs/contracts/` 下，由数据源维护者单写） | 在途请求（排队、限速、等上游）与最近完成请求的逐次尝试 | 外部网关没运行时 `reachable=false`，在途为空，但最近完成的记录照常返回。 |

## 场景结构（跨端复用）

前端的 `src/features/gateway/routingScene.ts` 把数据源变成与平台无关的场景，Android 端按同样字段实现即可：

- `sources[]`：每个来源 `{ id: tokenledger | external, reachable, note?, readError? }`。
- `flows[]`（最新在前）：`{ id, source, agent, via, hops[], phase, at, waitingOn?, fresh }`。
  - `hops[]` 按尝试顺序：`{ target: "供应商/模型", outcome: ok | failed | rejected | skipped | pending, status? }`。
  - `phase`：`inflight`（在途）、`routed`（已接通，可能仍在流式）、`done`（已结束且成功）、`failed`（没有成员接通或请求失败）。
  - `fresh`：记录距今不足 12 秒（`FLOW_LINGER_MS`），只有新鲜的流才播放；时间在未来的记录（时钟偏差）不播放。
- `agents[]` / `targets[]`：最多 4 个 Agent、5 个上游，多出的折叠成 `+N` 节点；节点 `state` 取最新一条流的结果（ok / failed / busy / idle），失败节点带状态码。
- `stats`：在途、已改道（尝试多于一次）、失败。
- `empty`：`no-source`（没有可达来源且没有记录）或 `idle`（有来源但没有请求）。

布局 `layoutRoutingScene` 只算数字：三列（Agent 左、网关居中、上游右），行距均匀，连线是水平 S 形三次贝塞尔。

## 动画时序

| 元素 | 表现 |
| --- | --- |
| 空闲连线 | 细线，边框色。 |
| 在途 | Agent→网关、网关→上游两段连线虚线流动（0.7 秒一周期），网关外圈脉冲，网关上方一个圆点闪烁表示在等待。 |
| 新鲜的已结束流 | 一个短光点先跑 Agent→网关，再按尝试顺序依次跑网关→各成员；每段 0.7 秒，间隔 0.25 秒；尝试很多时整段压缩到 4 秒内，开始播放后即使过了停留时长也播完。折叠进 `+N` 的 Agent 或成员，光点从折叠节点出发或落到折叠节点。失败的一段光点变危险色，跑到接近节点后回弹消失，节点挂上状态码标签；随后光点跑向下一个成员。 |
| 停留 | 结束后连线按结果保持点亮 12 秒（成功绿色、失败危险色虚线），然后回到空闲。 |
| 说明 | 舞台下一句话（`aria-live="polite"`），如「codex 的请求（group/coding）：openai/gpt-5 返回 429，已切换到 deepseek/deepseek-chat，已接通」；过期时前缀「最近：」。 |
| 减少动态效果 | 关闭全部动画，只保留点亮状态与说明。 |

颜色全部取自 `src/styles/tokens.css`：Agent 用 `--chart-1/2/7/3`（不用红、绿、琥珀，避免和状态混淆），成功、失败分别用 `--color-success`、`--color-danger`。
