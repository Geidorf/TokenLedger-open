# 网关请求内容采样（本机受限采样）

状态：实施中。2026-10-24 提出的方向已经 B 级评审认可（PR #82），实现按 B 级独立评审。使用 ring、密钥丢失即删样本、明文不进日志与错误、样本排除在同步与备份之外。关联：[gateway-request-log-v1](gateway-request-log-v1.md)。

## 要解决的问题

请求日志只有元数据。排查「为什么这次回答很差」「上游到底收到了什么」时，用户有时需要看到某几次请求的实际内容。但请求内容里常有源码、密钥片段和个人信息，默认记录内容不可接受。

## 原则

1. **默认关闭**，且每次启动后保持用户上次的选择；升级不会替用户打开。
2. **只在本机**：采样内容不进云同步、WebDAV、挂件、壁纸、CSV 导出与诊断日志；`gateway_routing_feed` 不变。
3. **加密落盘**：内容只以密文存在磁盘上。
4. **明显提示**：开启期间网关页、请求日志页与托盘菜单都显示「正在采样请求内容」，带一键关闭。
5. **有界**：条数、单条大小、保留时间都有上限，到期自动删除。

## 方案

### 开关与范围

- 独立采样配置：`off`（默认）| `next`（只采接下来的 N 条逻辑请求，N 默认 20、范围 1–200，采满自动回到 off）| `filter`（只采匹配条件的请求：指定 Agent、路由组或「只采失败请求」，最多开 24 小时，到时自动关闭）。不提供「永久全采」。配置单独保存剩余数量和截止时间，重启校验钥匙串后恢复，不增加数量或延长时间。
- 开启时弹确认：说明会记录什么（请求与回复正文，含系统提示、工具定义与工具结果、附件只记类型和大小不记内容）、存在哪里、保留多久、如何删除。

### 存储与加密

- 文件：网关目录下 `samples-v1/<逻辑请求ID>.bin`，每条一个文件，便于逐条删除。
- 密钥：首次开启时生成随机 256 位密钥，存进系统钥匙串（与供应商 key 同一个 `SecretStore`，账户名 `content-sampling-key`），不写文件、不进同步。
- 算法：用依赖链里已有的 `ring::aead`（`CHACHA20_POLY1305`），不新增依赖；每条独立生成 96 位随机 nonce，附加数据包括版本、固定格式的逻辑请求 ID 与采样时间，防止文件互换。
- 上限：单条明文最多 256 KB（超出截断并标注），总量最多 200 条或 50 MB，保留 7 天；按最早到期先删。启动维护和删除时也清理中断写入遗留的密文临时文件。关闭采样时询问「同时删除已采样内容？」默认勾选。
- 钥匙串不可用（例如 Linux 没有 Secret Service）时不允许开启，不退回明文。钥匙串里的密钥丢失或不可读时，直接删除全部样本并提示，不尝试恢复。
- 样本目录明确排除在 WebDAV、云同步、备份导出与诊断包之外，并在 ACL / 契约测试里断言。

### 读取与展示

- 仅主窗口命令（B 级）：`gateway_content_sampling_status`、`gateway_set_content_sampling`、`gateway_read_content_sample(id)`、`gateway_delete_content_samples(ids)`。`ids` 为 `null` 时清空全部样本。状态只返回开关、限制、样本 ID 与数量，不包含正文。读取在后端解密，只返回给主窗口展示，前端不持久缓存；解密后的明文不进 `log::`、panic 信息、错误字符串与 IPC 错误。关闭详情即丢弃，迟到结果不能恢复已关闭内容。
- 请求日志详情多一个「内容」分区，只有该条有采样时出现；默认折叠，点开才读取。
- 显示前对常见密钥格式（`sk-…`、`Bearer …`、`AKIA…` 等）打码，可点「显示原文」。

### 采样点

- 在网关完成认证、解析并确认目标后预留一次逻辑请求采样，重试或切换不会重复消耗限量。原始请求头不进入采样路径。回复结束后保存客户端收到的最终回复，流式拼接文字与工具调用，不存逐个事件。
- 最多同时持有 8 条在途或待落盘票据；剩余数量的持久化在线程池处理，转发前最多等待 100ms，超时或繁忙时跳过当前请求并在状态中提示。超时请求可能已消耗一次采样名额，但不保存正文，也不无限等待磁盘。手动关闭、清空或到期会撤销在途票据，已关闭的授权不能被迟到回执恢复。限量自动归零仍接纳归零前已预留的票据。
- 内容解析独立设置内存上限，附件字段递归剥离。无效或截断的 JSON 不以原始正文作为兜底；无法可靠识别的内容明确标为不可得。文件只包含版本、时间、随机 nonce 和密文，删除与读取拒绝路径穿越及链接文件。

## 平台边界

- 系统钥匙串不可用时功能不可用，不回退文件密钥或明文。Unix 样本目录和文件限制为当前用户权限；Windows 继承应用数据目录权限，内容安全同时依赖系统钥匙串和认证加密。
- 「只采失败请求」在回复结束时决定是否保留；中途断开、传输错误和明确的流错误均按失败处理。请求与回复始终有界，正文不进入一般诊断错误。
- 原生钥匙串交互、托盘显示和真实服务商流式响应属于平台验收；静态权限检查、内存夹具和本机 HTTP 测试不替代该验收。
