# T10.143b · Android 方案 B 交互与视觉规格

> **实施状态（2026-10-17 按代码核对）**：页面结构仍有效（REQ-ANDROID-02a）；视觉条目以 `../android-visual-refresh-v2.md` 为准。

> 适用范围：Android TokenLedger 的现有 `StatsData`、Quota v1 和本地展示状态。基准：`2b6f4be`。本规格只定义导航、层级、状态文案与组件迁移；不改变任何 Token、缓存、成本、Provider 新鲜度或 `unknown` 语义。

## 1. 总体结构

一级目的地固定为：**今日 / 复盘 / 额度 / 展示**。390×844 使用底部导航；宽度足以显示 rail 时仅把同四项导航换为 NavigationRail，目的地和返回行为不变。

| 目的地 | 用户问题 | 首屏只保留 | 不放入 |
|---|---|---|---|
| 今日 | 今天怎么样，为什么变了？ | 当前范围、主指标、同期变化、一个变化原因入口、紧凑来源/额度摘要 | 完整排行、全年日历、完整窗口列表 |
| 复盘 | 发生在哪、由谁造成、何时发生？ | 趋势、来源、日历、明细的连续工作区 | 第二套范围状态、重复的首页摘要 |
| 额度 | 需要立即留意什么？ | 需关注、可用、历史三组 Provider 窗口 | 与窗口数混淆的“来源数”、技术协议说明 |
| 展示 | 如何长期看或分享？ | 全屏摆件、Launcher 小组件、周期分享三个入口及各自预览 | 账户、显示主题等全局偏好 |

视觉层级统一为“页面问题 → 当前结论 → 一个主行动 → 支撑明细”。主数使用最大字号；状态、来源与时间只做辅助；品牌蓝仅用于当前选择、可操作入口、数据线与焦点，不为整块常规卡片染色。

## 2. 导航与返回链

```text
今日 ──查看变化原因──> 复盘 / 趋势
今日 ──继续复盘──────> 复盘（保留当前查询）
复盘 / 来源 ──工具──> 工具专属页 ──模型──> 模型专属页
复盘 / 日历 ──可信日期──> 当天复盘 ──返回──> 原日历位置
任一主页 ──设置────────> 设置 ──返回──> 进入前主页与滚动位置
展示 ──全屏摆件────────> 全屏摆件 ──系统 Back──> 展示
展示 ──周期分享────────> 分享预览 ──关闭──> 展示
```

- 复盘内部的趋势、来源、日历、明细是**同一工作区页签**，保持范围、设备、工具、模型、搜索和滚动位置；页签是展示状态的唯一事实源。
- 工具→模型→实体用标题下方的可读面包屑（例如“复盘 · 来源 / codex / gpt-5.6-sol”）及系统 Back 逐级返回。不得把实体页伪装成新的一级目的地。
- 点击日历可信日期：保存进入前的 `DashboardQuery`、复盘页签和列表位置，打开当天复盘；返回时全部恢复。未来、未知覆盖日期不可点；可信空白日才表现为已知零。
- 设置仅保留强制横屏、外观、账号与真实可写设备偏好。有效 Token、缓存、Stats v2、快照含义移到对应卡片的“这是什么”帮助入口，帮助只解释，不可写。

## 3. 页面级规格

### 3.1 今日

1. 顶部为当前查询摘要与筛选入口；日期范围是唯一可调整的全局范围。
2. 主卡依次为：当前口径/下一步切换提示、主数与同期变化、成本（若未隐身）、一张趋势摘要。
3. 主 CTA 为“查看变化原因”，进入复盘趋势并定位到当前峰值/异常时段；次 CTA 为“继续复盘”，进入复盘保留当前页签默认趋势。
4. 下方只保留一张紧凑来源摘要和最多两个可绘制百分比 Provider 额度摘要；分别进入复盘来源和额度，不能再放完整曲线、全年日历或完整额度墙。
5. 无数据时主卡直接说明“这个范围还没有可解释的消耗记录”，保留改范围与打开筛选的行动；不得以零值曲线代替空态。

### 3.2 复盘

- **趋势**：主曲线、同进度比较、最近三行精确时段表；展开才显示完整表。当前期空、上一期缺失、部分桶不可得三者各自说明。
- **来源**：工具/模型按现有可见组最大值画数据条，保留精确值、占比或请求和可点击下钻。模型的 Token / 金额为同一张卡的指标切换，不复制第二张排行。
- **日历**：全局年度热力图只高亮当前范围；点击月打开原生日期选择器，点击可信日期进入当天复盘。日期格不叠加小于 48dp 的独立触点。
- **明细**：搜索与筛选置于列表前；每行保持工具、模型、时间/设备、有效 Token、成本、输入/输出/缓存/请求的稳定顺序。金额隐身时数值、图形和 TalkBack 同步隐去。

### 3.3 额度

Provider 仍按 Codex、Claude、Antigravity、其他的稳定顺序，窗口仍按既有 Quota v1 规则取值。

| 分组 | 进入条件 | 默认呈现 | 行动 |
|---|---|---|---|
| 需关注 | error/需授权、stale、或剩余量触发警示 | 展开；先显示状态与最近重置，再显示窗口 | 查看详情/诊断 |
| 可用 | 有可信、可绘制窗口 | 展开；按 Provider 展示合法窗口 | 展开/收起详情 |
| 历史 | LKG 或窗口观测已过期 | 默认折叠；标题写“历史数据”与最近 `observedAt` | 展开查看原因与窗口 |

`0 Credits`、百分比和未知重置均保留原量纲；不把历史改为错误、不把 unknown 改为零或“已刷新”。卡片详情必须继续展示快照生成时间、逐窗口 `observedAt` 和重置的未知状态。

### 3.4 展示

- 首屏三个等层入口：**全屏摆件**（应用内长期展示）、**Launcher 小组件**（系统桌面入口）、**周期分享**（9:16 海报预览）。
- 三者只归类到同一“展示”目的地；各自现有的实例配置、系统权限、分享动作和验收边界不合并。
- 全屏摆件沿用现有主数、趋势、热力、两项额度与低功耗策略；系统 Back 返回展示。Launcher 区必须说明“在桌面长按添加/重新配置”，不在应用内伪造已添加实例。分享先选周期与布局，再打开系统分享面板；未选目标 App 不视为已分享。

## 4. 状态规范

| 状态 | 内容规则 | 行动与返回 |
|---|---|---|
| 首次加载 | 保留页面标题、查询与已进入的面包屑；内容用同尺寸骨架 | 不隐藏返回；完成后原位替换 |
| 刷新中且有数据 | 保留 LKG，顶部写“正在刷新”；不闪回空白 | 可继续浏览；失败转“刷新失败，显示已有数据” |
| 空态 | 说明哪一层为空（范围/来源/明细/Provider） | 提供调整范围、清筛选或返回上层；不编造零值 |
| 错误 | 保留路径与可用旧数据；错误说明可恢复原因 | “重试”只重发当前查询，Back 不丢查询 |
| 历史 | 真实显示 observedAt、历史原因和数据范围 | 默认折叠仅适用于额度历史组；展开不触发刷新 |
| 未登录/鉴权过期 | 隔离为账户状态，不与无数据混写 | 登录或重新验证；取消后停留在安全说明 |

## 5. 尺寸、重排与无障碍

### 5.1 320–430dp / 390×844

| 宽度 | 规则 |
|---|---|
| 320–359dp | 主卡主数与成本上下分轨；来源/额度摘要单列；四个复盘页签保持文字且可横向滚动，不能压缩为只图标。 |
| 360–430dp | 主卡可双轨；来源、模型和额度行维持“名称 / 数值 / 下钻”三轨；卡内统计依内容高度换行。 |
| 390×844 基准 | 今日主卡、主 CTA 和至少一组摘要应在一次自然滚动内读完；复盘页签固定于查询摘要之后，列表/日历各自滚动。 |

- 所有可点击行、图标、页签和日历入口最小 **48dp**；视觉图标可较小，但命中区不可较小。
- 文字放大时优先换行、单列、展开详情或显示 `+N`，不缩小字号、不截断数值、不把多列硬塞。
- 深浅色与 E-ink：状态必须是文字+图形的双重编码；热力强度有文本摘要，额度状态有“需关注/可用/历史”等非颜色标签。

### 5.2 TalkBack 文案

| 控件 | 必含语义 |
|---|---|
| 底部导航 | 当前目的地、目标目的地、双击动作 |
| 主指标 | 当前口径、当前值、切换后的口径；使用 Switch 语义 |
| 趋势 | 指标、范围、当前/上一期、峰值、可打开精确表 |
| 来源行 | 工具或模型、精确 Token、占比/请求、打开下钻 |
| 日历 | 年月日、强度文本、是否当前范围/可选、打开当天复盘 |
| 额度窗口 | Provider、窗口、可用量、状态、重置、observedAt；unknown 明说未知 |
| 展示入口 | 类型、当前能力、下一动作；不把系统能力描述成已完成操作 |

## 6. 现有组件与数据投影迁移表

| 现有符号（`LedgerDashboardV2Ui.kt`） | 保留 / 迁移 | T10.143b 影响类别 |
|---|---|---|
| `MobileDestination`、`V2NavigationBar`、`V2NavigationRail` | 四个 enum 标签改为今日/复盘/额度/展示；选择与返回状态保留 | 导航壳 |
| `v2OverviewItems`、`V2HeroCard`、`V2ToolDistributionCard`、`V2QuotaSummaryCard` | 收束到今日：仅摘要和两个出口 | 今日层级 |
| `v2InsightsItems`、`V2TrendInsightCard`、`V2SourceAnalysis`、`V2InsightCalendarCard`、`V2DetailSearch` | 合并为复盘工作区；页签和筛选状态继承 | 复盘层级 |
| `V2EntityContent`、`V2EntityHeroCard`、`V2EntityModelsCard` | 连续面包屑/Back，不升为一级页 | 下钻链 |
| `v2QuotaItems`、`V2ProviderCard`、`V2QuotaProviderDetails`、`V2QuotaWindow` | 按需关注/可用/历史分组；窗口投影不变 | 额度呈现 |
| `v2WidgetItems`、`V2WidgetModeStrip`、`V2AmbientModePreviewCard`、`SharePosterSheet` | 归入展示的三个入口，保留现有系统边界 | 展示归类 |
| `V2SettingsPage`、`V2DataSettings`、`V2WidgetSettings` | 删除常驻口径/缓存/协议说明；保留可写偏好与就近帮助 | 设置收口 |
| `retainedDashboardData`、`V2PaginationErrorCard`、`V2TopBar` | 扩展为路径不丢失的加载/错误容器 | 状态连续性 |

以上项目都只读取既有 `DashboardUiState`、`StatsData` 与 Quota envelope；**不新增** RPC、迁移、扫描、同步或云端字段。

## 7. 开发验收清单

1. 四个一级标签、标题、选择态和 rail/bottom-nav 一致；从任意目标返回不丢查询或滚动状态。
2. 今日不再复制完整复盘内容；三个出口能抵达对应连续路径。
3. 日历点击进入当天复盘，再返回能恢复日期范围、筛选、页签与位置。
4. 额度历史默认折叠，未知、历史、错误、需授权及正常窗口各自可区分。
5. 320dp、390×844、430dp 与 200% 字体下无截断、重叠或小于 48dp 的触点。
6. TalkBack 能读出主数切换、图表摘要、日历强度、额度时效和所有下钻动作；真实语音仍需独立验收。
