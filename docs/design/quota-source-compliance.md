# 订阅额度来源的合规边界

> 公开版说明。内部调研原文（含具体端点、实现细节与本机探测数据）保留在私有仓库，不随本仓库公开。
> 关联：ADR-004（额度来源红线）、ADR-018、契约 `docs/contracts/quota-provider-v1.md`、能力矩阵 `docs/integrations/quota-provider-capabilities.md`。

## 结论

1. **不读取、不复用消费者订阅的登录凭据。** 不复制 OAuth token、refresh token、钥匙串条目、浏览器 Cookie，不读取任何登录凭据文件。
2. **不调用消费者产品的未公开内部接口。** 只使用官方文档支持的 API、用户显式授权的本地来源，或用户手工配置的第三方端点。
3. **只借鉴交互，不借鉴取数方式。** 值得借鉴的是交互设计：导入对话框式本机检测、账户卡片、窗口进度条与重置倒计时、旧值标注「截至何时」、错误转成一句可执行的提示。
4. **合规来源只有三类**：官方文档化的账户 API（用户自己的 API key 发往该供应商自家域名）、用户显式授权的本机来源（CLI status line、本机 loopback 服务、用户手工配置的第三方端点）、以及手工配置的额度信息。
5. **无公开文档的端点一律标为 `experimental`**：默认关闭、需用户逐来源确认风险、consent 版本变更即失效。风险提示与字段白名单见能力矩阵 §3 与 §5。

## 为什么划这条线

| 风险 | 说明 |
|---|---|
| 账号封禁 | 第三方客户端以用户身份调用消费者接口，可能被识别为自动化滥用，导致订阅受限或封禁 |
| 条款 | 各家消费者条款普遍限制自动化访问与第三方使用用户凭据 |
| 接口变动 | 私有接口无版本承诺，字段随时可能变化，维护成本持续存在 |
| 凭据暴露面 | 复制或缓存 refresh token 会扩大本机凭据暴露面，与「凭据不出系统安全存储」的承诺冲突 |

## 实现侧如何落实

- 本机额度来源检测只判断路径与可执行文件是否存在，**不启动进程、不打开凭据或登录文件**，结果不进入同步 envelope 与日志。
- 自定义额度端点强制 HTTPS（loopback 允许 HTTP），禁止 URL 内嵌凭据、禁止 query 与 fragment、禁止重定向，固定 Bearer 认证头与超时上限，并按 URL 绑定凭据。
- 实验性来源需用户确认当前风险提示版本后才启用；未确认时既不读凭据也不发请求。
- 额度快照只保留白名单字段，不保存请求原文、账户身份、路径或提示词。
- 云端与移动端永不接触额度来源的 URL、key、金额或原始 JSON；只同步标准化后的百分比与重置时间。

## 来源分级

| 类别 | 取数方式 | 状态 |
|---|---|---|
| 官方账户 API | 用户自己的 API key，发往该供应商自家固定域名 | `stable` |
| 官方文档化的组织 API | 组织管理 key，按组织/项目维度聚合 | `supported`（按需接入） |
| 本机显式授权来源 | CLI status line、本机 loopback 服务、用户手工配置的端点 | `experimental`（默认关闭 + consent） |
| 手工配置 | 用户自行填写的额度或预算 | `manual` |
| 消费者订阅凭据 | 复用 OAuth / 钥匙串 / Cookie | **禁止（ADR-004）** |

## 实验性来源例外

上表「禁止」之外，以下来源是明确列出的例外。两者都标为 `experimental`，且必须同时满足下方门禁：

| 来源 | 性质 | 边界 |
|---|---|---|
| 三类套餐额度端点：智谱 GLM（`open.bigmodel.cn`、`api.z.ai`）、MiniMax（`api.minimaxi.com`、`api.minimax.io`）、Kimi Code（`api.kimi.com`） | 无公开文档的供应商端点 | 只用用户自有 API key，只发往上述供应商自家域名（固定允许列表）；只输出可验证的百分比窗口，不推断速度或官方重置承诺 |
| 本机 Antigravity 回环 RPC（`127.0.0.1` 上的额度与状态 RPC） | 本机授权来源 | 只请求同用户已运行的 App/IDE/agy 或短暂自启的 agy 所提供的回环服务；专用 client 才允许本地自签名证书；账户身份丢弃 |

**门禁（全部适用）**

- 默认关闭；用户在设置页逐来源开启，并确认当前风险提示版本（`RISK_VERSION`）。版本变更后确认失效，需重新确认。
- 不读取或复用消费者订阅的登录凭据、OAuth token、钥匙串条目，不读取或复用浏览器 Cookie 与网页会话。
- 固定 HTTPS 域名或 `127.0.0.1`，禁止重定向，连接与总时长、响应字节数有上限。
- 只保留白名单字段；原始响应、账户身份、路径与提示词不进入 envelope、日志或云端。

## 自检清单

- [x] 额度来源不需要任何消费者订阅凭据即可工作
- [x] 未公开端点仅出现在 `experimental` 实验来源中，且受默认关闭与风险确认门禁保护
- [x] 未读取钥匙串、浏览器 Cookie 或 OAuth 凭据文件
- [x] 无公开文档的来源默认关闭并需显式 consent
- [x] 云端与移动端只接收标准化 envelope

## 第三方来源

本仓库只参考了**公开文档化的**第三方能力说明，并对每类来源独立重写了受限子集。实现不依赖任何第三方私有接口。
